# Peak-Powerhouse
An RDMS solution for a mid sized fitness organization implemented using python and MySQL.

# Installation Instructions
1 - Generate .env file in project folder containing the following:\
    DB_HOST=your_host\
    DB_USERNAME=your_username\
    DB_PASSWORD=your_password\
    DB_NAME=your_db

2 - Set up virtual environment, activate, then install the following modules:\
    mysql.connector\
    dotenv
